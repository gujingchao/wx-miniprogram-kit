# cloudfunctions

WeChat Cloud Development (云开发) style stubs. Each folder is a cloud function with `index.js` + `package.json`.

**For local demo and contract testing, prefer [`../mock-api/`](../mock-api/).** These stubs are scaffolding only — not a full 云开发 backend.

| Function | Purpose |
| --- | --- |
| `login` | Mirror login profiles (`user` / `admin`) |
| `upload` | Return a mock upload URL |
| `ping` | Health / connectivity check |
